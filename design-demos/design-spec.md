# 「量化实习成果看板」视觉升级方向设计规格

## 本次任务边界

本轮只做视觉方向提案，不修改现有 `site/`、`content/`、构建脚本或任何功能逻辑。三个原型均使用项目中的真实栏目、阶段名称与报告数据，用独立 HTML 演示同一个产品在不同视觉系统下的样子。用户选定方向后，才进入正式实现与设计系统落地。

## 顾问式理解

这个项目不是常规的量化交易后台，也不是对外售卖策略的营销页；它更接近一份可以持续生长、可检索、可回看、能在汇报场景中建立可信度的「研究成果档案」。主要受众应当是导师、同事、面试官或未来的自己。他们需要在几秒内明白实习研究推进到了哪里，又能进入某个阶段或某篇日报，阅读长篇、图表密集、证据链完整的技术材料。因此，美化的本质不是给现有深色界面增加光效或卡片，而是把“导航效率、研究权威、长文可读性、阶段叙事”重新排序：第一眼看懂成果全景，第二步找到关键报告，第三步才进入细节。视觉上需要避免通用 SaaS 暗色模板、无意义圆角和装饰性图标，同时保留量化研究应有的精确、克制与数据感。基于这个理解，我直接做 3 个结构、色彩与排印逻辑明显不同的真实版本供审阅。

## 使用场景与受众

- 主要设备：笔记本与桌面浏览器，基准画布 1440 × 900；响应式下沉到平板和手机。
- 主要受众：内部导师、研究团队成员、求职面试官、本人后续复盘。
- 核心任务：浏览六个研究阶段；快速定位最新或重要成果；阅读长篇日报；在文档与展示模式之间切换；搜索；下载报告。
- 情感基调：可靠、聪明、清醒、有研究者人格。不是券商交易终端的压迫感，也不是学生作业网站的稚嫩感。

## 内容与信息架构

三版必须保留且使用同一组真实内容：站点标题「量化实习成果看板」；正式成果与每日汇报两个主视图；数据处理、快照构建、算法痕迹检测、因子构建、模型搭建、交易策略六个阶段；最新报告「开盘五分钟算法痕迹新因子：490 个正式候选全景报告」；真实摘要中的 490 个正式候选、5 个诊断列、135 个逻辑家族、1,980 张评价图；最近日报列表与阶段状态。提案只重排这些信息，不编造收益率、IC 数值、交易业绩或用户评价。

## 图片需求判断

这是工具、数据与文档型产品，图片不是内容必需项。项目真实价值来自文本、阶段结构、图表和报告数据；加入图库照片会稀释专业性。三版不使用装饰性 stock photo，也不画伪产品图。视觉锚点由排印、真实数字、阶段编码、规则线和数据形态构成。后续正式实现时，报告中的真实图表继续作为正文证据出现，而不是作为首页装饰。

## Form 推导五问

1. 叙事角色：首屏是「成果全景 + 当前研究焦点」，不是普通欢迎页；日报页是「研究档案阅读器」。
2. 观众距离：主要是 1 米左右的笔记本阅读，标题要能扫读，正文需长时间舒适，数据与标签必须清晰。
3. 视觉温度：方向一偏兴奋与前进，方向二偏权威与沉静，方向三偏好奇与人文；都不能像博彩或交易软件。
4. 容量估算：首屏同时承载品牌、双主导航、六阶段、当前成果、关键数字、最近日报六类信息，必须通过层级和栅格消化，不能全部装进卡片。
5. 视觉母题：方向一用「行情信号带」表现研究推进；方向二用「研究报纸与档案索引」表现可信度；方向三用「数据轨迹与采样地图」表现个人研究旅程。三个母题都直接来自量化研究内容，而非套用无关风格。

## 三方向共同底线

- 正文不小于 14px，说明文字不小于 12px，正文对比度达到 WCAG AA。
- 不使用 emoji 图标、通用紫色霓虹、圆角卡片加左彩色边框、装饰性 KPI 或伪数据。
- 每版首屏必须有明确视觉锚点，不能只靠大片留白。
- 三版的导航、构图或内容骨架至少一项结构性不同；不是换色皮肤。
- 原型可双击打开，主导航可在「正式成果」「每日汇报」间切换；阶段和日报条目有基本可见交互反馈。

## 方向生成记录

- 方向 A「信号切面」：秒数轮盘为 53，`53 % 20 + 1 = 14`，对应网页风格库第 14 项「斜切流体渐变带」。不复制 Stripe 的紫色配方，而从项目六阶段低饱和色中收敛为青绿、赭黄、珊瑚与墨黑，用斜切行情带承载研究进度。
- 方向 B「研究编辑台」：现实标杆选择 Fathom Information Design。迁移其「把密集信息变成可理解、可探索的工具」思路，以编辑部式索引、结论标题和极少容器建立专业性。
- 方向 C「数据旅程图谱」：最佳设计师视角选择 Giorgia Lupi / Pentagram 的 Data Humanism。迁移其把数据视为故事语言的哲学，用线、点、编码和注释把六阶段塑造成可阅读的研究轨迹，同时保持金融研究所需的克制。

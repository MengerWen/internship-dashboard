## 补充说明

**全项目纯 C++ 底座合流与硬红线（补自 T3 Code 会话）。** 全天通过 T3 Code 多路并发推进，16:55 完成原始 22/22 项纯 C++ 迁移任务全部合入 `sirui-quant-research` 主线，包括公共共享库 `opening_cpp`（净删 386 行重复代码）、深市 344 列全 C++ 驱动、沪市 340 列全 C++ 驱动以及沪深定参纯 C++ 引擎，同时拉齐了两台服务器（`wangly`、`wenjie`）的原生编译工具链与无 Python 离线测试。当天明确了三项原则：绝不牺牲 100% 数学正确性（0 ULP）、从第一性原理做算法与 I/O 提速、两台服务器配置完全对等；同时将研究仓分支规则精简为轻分流主干开发（TBD），并整理出脱敏版《算力服务器与计算效率实战避坑手册》供新实习生上手。

**深市 344 列两日在线复验。** 极端日离线回放从 62.95 秒降到 45.16 秒。在线首轮因一只股票的逐笔输入顺序与冻结版不一致而中断，修复后两日 5,732 个股日输入完全对齐，197 万个因子值逐位一致。放宽页缓存预算后，双日成功耗时比前版提速 42.9%（64.12 秒），次日提前开算的股票数从 8 只增至 2,883 只，但最重一只股票自身耗时从 47.97 秒升至 61.58 秒且内存等待变多。晚间合入默认 Arrow 页预算估算修复（按实际内存占用留 40% 余量并支持自动缩窗重试），修复版连续吞吐和 683 日两小时目标留待实测。

**Doris 公共取数提速。** 同代表日、同股池对照下，取数、逐股校验和封包合计从 12.00 秒降至 6.31 秒，2,884 只股票输入完全一致；接入自适应分页后，代表日 SQL 查询数从 383 条减到 138 条。

**沪深定参进展与晚间主控切换。** 深市定参复验三日共 47.26 秒（日均 15.76 秒），跨日预取生效，极端日定参 188.81 秒，代表日结果与单核对照逐位一致；沪市 340 列和定参独立入口已合入，真机双日对照留待次日。晚间 22:22 将总控统一交接至“双主线 × 双市场（沪深因子与定参四格）”协同推进。

**网站 C++ 发布构建合入。** 前一日验证通过的独立 C++ 构建器合入主线，9,136 个产物与冻结 Python 版逐字节一致，冷构建 22.97 秒、暖缓存 6.87 秒（均计至全文搜索索引完成）。

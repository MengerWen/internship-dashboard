## 补充说明

**深市 344 列提速与全期外推。** 剪掉旧单序号不可能匹配的候选后，代表日（按历史负载第 75 百分位选定）两轮耗时 23.10 和 23.12 秒，极端日从同轮基线 147.38 秒压至 140.90 秒；极端重股 61,733 条最优买卖报价匹配入选边也通过独立核对。按该版本外推，683 日点估计 4.76 小时、保守估算 5.77 小时，仍高于 2 小时目标。分析发现其余 80 个重负载日合计多花约 43 分钟，只压单日极端日到 60 秒只能省约 1.35 分钟，必须同步压低普通日与重日均值。未见收益的几项试验（BBO 提前启动、整手对数表、原生页读取）已撤回。

**沪深定参与正式计算基线。** 两市定参统一以日均 8 秒为目标。沪市含极端股三日全池重估覆盖 6,845 个股日，结果与前版对齐，日均 660.00 秒；深市三日覆盖 8,543 个股日，按候选量均衡派工后日均 258.19 秒（同调度器下此前 C++ 与 Python 分别为 327.10 和 336.04 秒/日，仅提速 1.03 倍）。沪市 340 列代表日完整流程耗时 298.42 秒，同样离 10 秒目标很远。深市已把开盘五分钟 C++ 深度内核接到正式入口，三股日 24 列核对一致。

**三仓迁移盘点与暂停。** 盘点了全部 3,649 个 Python 与笔记本文件的调用边界：共用取数、集合竞价、六核拟合和四来源合并已做出 C++ 模块，外围调度、验收、训练与回测仍走 Python。17:37 按要求暂停在途沪市试算并保留三日已算结果，7 月 16 日重股匹配和最终参数包留待后续。

**看板 C++ 工具。** 工作区盘点、导航后处理、搜索页和日报下载页接入 C++，227 组页面渲染与冻结 Python 结果逐字节一致；因跨 Python 进程调用开销，当前微测反而略慢，全站构建暂仍由 Python 驱动。

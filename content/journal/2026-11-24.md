## 补充说明

**深市 683 日全天算力摸底收官。** 按 L1 成交笔数给三张逐笔表分页、切为二进制取数并做跨日调度后，重日采集耗时从 80.06 秒压到 39.21 秒且逐股结果完全一致。227 日冷跑 47 分 05 秒通过 1 小时门槛，随后顺势跑完剩余 456 日（总跨度约 2 小时 59 分，含早盘冻结与一次 Doris 中断恢复）。全期 683 日覆盖 195.72 万个股日、约 1,385.08 亿条有效逐笔，开盘五分钟占全天配对机会约 34.8%；仅按开盘五分钟挑最重 10% 交易日会漏掉 14 个全天配对重日。352.9 小时仍是按负载倍数推算的条件估值，长窗真实求解耗时待实测。

**拍板全项目迁 C++ 与自动化总控启动（补自 T3 Code 会话）。** 白天沪市 340 列最快代表日做到 194.30 秒（2,266 股四来源面板与六个频道时钟核对一致），沪市定参七月三日共 423.01 秒（日均 141.00 秒），深市定参三日日均 282.19 秒，仍离各自速度门槛很远。晚间在 T3 Code 暂停零散手工优化，正式决定将研究项目的 8 条核心业务全部迁至可脱离 Python 独立运行的 C++ 底座（三仓 3,659 份脚本/笔记本分类为 572 份现役迁移、158 份冻结对照、2,929 份历史封存），并启动由 Gemini 4 Neon (High) 统筹规划与验收、多路 Codex 并发在独立 worktree 中实现的自动化迁移总控。当天已完成沪市独立入口首批 68 列回放与连续账簿 8 日样例对照。

**深市 344 列同版对照。** 同版端到端重跑代表日 27.91 秒、极端日 140.54 秒（与历史最快版同批复测均未复现 23.10 秒），保留 64 列分块并撤回无稳定收益的传输改动，683 日保守外推约 5.77 小时；晚间同步在 T3 Code 启动深市重股算法提速专项（Track S）。

**报告重写、看板与存储。** 将 11 月 22 日展示页按“立项前算力摸底账单”思路做了通俗化改写和可视化增强并上线，227 日提速过程单列在 11 月 23 日技术报告中；网站把研究日志固定来源核验与登记工具迁入 C++（独立发布构建在本地分支对齐冻结产物）。存储清理释放用完的热暂存，并为对象列表超时补上分层列举兜底。

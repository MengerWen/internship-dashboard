# 深市328列因子：逐股票日参数下的601日全期成果

报告日期：**2026年10月18日**。数据期为2024年1月2日至2026年6月30日。

深市开盘五分钟的328列冻结模型输入，已覆盖全部601个交易日、1,719,612个股票日，完成四来源计算、逐日科学验收、全量内容校验和正式结果发布。本轮复核并复用271个已验收日期，补齐其余330日、948,702个股票日；最终没有未解决的日期或来源失败。

本批老因子使用逐股票日六核参数与正式结构参数v2，另外72列沿用各自冻结定义和参数。最终保留256列老因子、买侧撤单相位24列、卖侧撤单相位24列和深度匹配24列，按原模型输入顺序合并。**“328列全部交付”指文件、列、日期、股票日键与科学验收完整；个别股票日上的因子仍可以按定义为NaN。**

全表共564,032,736个特征单元，其中557,600,704个为有限值，有限值覆盖率为98.859635%。276列的全期覆盖率不低于99%，但这个总量掩盖了明显差异：`f96_algo_time_weighted_spread_wide`买卖两列均只有38,494个有限股票日，覆盖率为2.238528%。报告保留这两列，不以整库成功替代逐列质量判断。

本次完成的是新参数下的因子数据与计算验收。9月16日报告的R19因子值、收益相关、分组收益、OLS和排名不直接适用于本批数据；本报告不把旧结果作为新一轮预测效果。科学验收通过，性能策略为`record_only`，性能门槛未通过。

### 老因子的五个层次

| 层次 | 本批列数 | 观察的问题 | 数值含义 |
|---|---:|---|---|
| L1 基础评分投影 | 130 | 撤单、重挂、订单链、执行与盘口响应是否出现 | 该方向的行为贡献相对于全部有效新委托的强度 |

常见投影为`F(side,d)=Σ该方向内订单贡献/N(d)`，其中`N(d)`是窗口内全部有效、去重的新委托数，买卖侧共用分母。共识、状态交互和特殊组合继续按注册定义计算，不能把所有列理解成相同的简单命中率。零值表示满足可观测条件后的零贡献，NaN保留未知或定义所需证据不足的状态。

旧注册表的284个正式输出和4个诊断输出中，本批只保留冻结模型指定的256列。排除32列的历史依据包括近乎全缺失、指定方向全零、诊断用途及冻结研究范围；这些依据没有统一的逐列删除消融，不能概括为“被排除的列预测效果差”。内部共享评分和审计依赖也不能随着最终输出列一并删除。

### 撤单相位：7族、2个周期、买卖分别计算

撤单相位使用年龄带`[1,10)`秒内的合格撤单消息。对周期`T∈{500,1000}ms`，将年龄折叠为`φ=age mod T`，并保留周期编号。前五族使用20ms、50ms两种heat核，后两族使用20/50ms的sharp核组合，每侧展开为`5×2×2+2×2=24`列。

| 族 | 观察内容 | 分母或比较对象 |
|---|---|---|
| cph01 事件对集中度 | 撤单相位是否集中 | 有序事件对与核归一量 |
| cph02 跨周期一致性 | 不同等待周期之间是否仍有集中 | 跨周期事件对 |
| cph03 交叉拟合总变差 | 分半估计的相位偏离能否相互支持 | 有效交叉拟合周期 |
| cph04 全委托归一能量 | 相位结构与撤单消息强度共同变化 | 全部合格新委托数的平方 |
| cph05 跨订单集中度 | 扣除同一订单内部配对后是否仍有集中 | 不同订单之间的事件对 |
| cph06 尖锐事件对集中度 | 较窄尺度相对较宽尺度的集中结构 | 事件对与sharp核归一量 |
| cph07 尖锐跨订单集中度 | 不同订单之间的尖锐相位结构 | 跨订单对与sharp核归一量 |

这些定义有不同分母和支持要求。特别是cph04不能无条件解释为落在[0,1]内的撤单率；跨周期、交叉拟合或跨订单支持不足时保留NaN。相位集中本身也不能证明特定交易者身份或真实算法意图。

### 深度匹配：12个定义，买卖两侧共24列

以提交前的合法盘口为基准，记录委托量`Q`与对手一档深度`D1`、二档深度`D2`的关系，再区分价格约束、执行确认、盘口变化及时间分布。

| 定义 | 名称 | 观察与限制 |
|---|---|---|
| dm01_exact | 提交量精确匹配一档 | 要求提交时可触及第一档，并且 Q=D1；按原始整数股数精确比较。 |
| dm02_confirmed | 执行确认的一档匹配 | 在精确一档匹配上要求初始主动撮合已确认结束且仅吃完原第一档，不能用生命周期总成交代替。 |
| dm03_price_room | 价格允许第二档 | 精确匹配一档数量，同时提交价格允许触及第二档，描述数量止于一档的行为。 |
| dm04_price_cap | 价格封顶第一档 | 精确匹配一档数量，且提交价格只允许触及第一档。第二档不存在或类型语义未知时不可判。 |
| dm05_lot_floor | 百股网格匹配 | 一档深度至少 100 股，Q 等于将 D1 向下取整到百股网格后的数量。 |
| dm06_soft_under | 一档以下软匹配 | Q 不超过 D1；只在一档以下 1% 容差内给线性权重，Q=D1 时得 1。 |
| dm07_fresh_match | 新深度匹配 | 精确匹配当前一档，且与严格早于一秒前的合法状态相比，最优价相同而数量不同；不要求中间路径价格始终不变。 |
| dm08_adaptive_repeat | 相邻变数量匹配 | 同股同向最近可主动成交前单与当前单都精确匹配一档，间隔不超过一秒且提交量不同；每张当前订单最多记一次。 |
| dm09_two_level | 两档累计量匹配 | 订单允许触及第二档，两档均存在，Q=D1+D2；此定义允许穿透第一档。 |
| dm10_excess_cancel | 超额提交后撤余量 | Q>D1，价格封顶第一档并确认主动吃完该档；初始撮合结束后 100ms 内全撤 Q−D1，期间无被动成交，且数量守恒。 |
| dm11_recent | 近期匹配 | 精确一档匹配得分乘以距 09:35 的指数权重，半衰期 60 秒；09:34 权重为 0.5，分母不加权。 |
| dm12_persistent | 持续匹配 | 每侧的精确匹配命中数 C/N 乘以五个一分钟箱的归一化熵。单箱集中得 0，五箱均匀熵为 1；C=0 且可判时得 0。 |

各列使用自己的资格和未知状态合同。一般按观测订单贡献除以全部有效新委托数；持续匹配另结合五个一分钟箱的归一化熵。提交量使用原始整数股数，盘口必须位于事件之前，执行确认和撤余量不能用最终生命周期成交量随意代替。

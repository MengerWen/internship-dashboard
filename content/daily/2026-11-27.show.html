双轨满速并发与版本解耦（Pin & Roll）

RULE 01
  • 工程轨全速去 Python 化：照常推进全仓 C++ 迁移与极端日提速，不降优先级；按业务杠杆优先交付六轴账簿、日摘要 PIT 定参与紧凑多截点流式引擎。
  • 研究轨绝不等终极完美版：随时锁定截至此刻最快且已验签的 C++ 版本推进实证；工程轨每产出更快已签版本，研究轨无痛切换加速。

四重全链 PIT 红线（零未来信息泄露）

RULE 02
  • 因子定参 PIT + 零拍脑袋窗口：日 t 参数严格只用 t−1 及之前数据；拆为「逐日紧凑充分统计量」+「O(N) 毫秒归约」，按实测方差收敛下界与漂移自相关尺度客观决定扩张窗或 EWMA 半衰期。
  • 训练与标准化 PIT：严格按日切分，跨边界未结算标签一律剔除。
  • 收益校准与容量预估 PIT：score → α̂i 映射与成交量上限严格只用事前历史与实时盘口，绝不偷看未来执行窗成交量下单。
  • 时钟与库存 PIT：报价、现金、可卖旧股严格满足 received_ts < decision_ts 并叠加计算与报单延迟。

全量心血保留与多截点算力三级降维

RULE 03
  • 不删任何重型因子：340/344 列微结构与 44 族已算新因子完整保留，按真实分组消融与边际贡献决定入模角色与权重。
  • 消除 S3 碎片开销：单日多截点合并为单一紧凑列式对象写出，直接削掉旧估算中仅对象碎片发布回读就占去的约 18.6 小时。
  • 两级探索漏斗 + 流式闭合：先在 60–80 个分层代表日（覆盖牛熊、缩量、重日及末 82 日）跑通地图（1–2 小时级）再扩至 683 日；单遍流式订单簿 O(1) 更新 + 局部闭合分量即时释放，稳守 100 GiB 内存线。

拒绝拍脑袋超参与严防数据窥探

RULE 04
  • 只认参数高原（Plateau）：回看窗、触发步长、执行时长、持有期与配权参数全部由无模型物理底图 + 粗-细网格得出，淘汰孤立尖峰。

四角色解耦与目标函数升级

1. 去风格残差 Alpha + 头部聚焦主模型 ROLE · PREDICT

主模型直接预测扣除市场、行业与市值后的纯残差收益，防止树模型学进伪 Beta；针对信号集中在 Top 1%–5% 的非对称形态，测试头部加权 / Top-K 排序 / 扣成本阈值目标，不让中间 80% 噪音带偏分裂。

2. 二级门控模型（Meta-Labeling） ROLE · GATE

专门吸收「单看 IC 一般、但大幅提升稳健性」的正交特征：日间 Barra 边际变化、全市场算法拥挤同步度（FAM-CROWD-SYNC）、活跃度与价差，预测主模型本次出手的扣费胜率与仓位缩放系数 p̂i。

3. 独立平仓模型（Exit Decoupling） ROLE · EXIT

将「启动延续（开仓）」与「衰竭回吐（平仓）」彻底拆分为独立模型与标签，支持主动反向信号提前了结与到期被动平仓的客观对照。

4. 事前盘口过滤与冲击函数 ROLE · FILTER / COST

严格 PIT 估计盘口档位深度与预期滑点函数 ĉi(q)，直接喂给层 3 的剩余收益率平价优化器，剔除扣成本后无净边际的伪机会。

跑的是哪一折，输入、目标和损失函数是什么

一个 CPU LightGBM 回归模型；一套参数、一个随机种子、一次训练。未开展网格搜索，也没有 GPU 对照。

VWAP 使用当日真实成交量加权。任一窗口无成交则标签缺失，不找替代价格。全天停牌剔除，ST、新股、退市整理期不额外剔除；进场封板仍进入回归训练。

X：每日横截面因子变换

对该日因子交集内全部有限值分别计算中位数与 MAD，不按未来标签是否有效筛选标准化样本。MAD 为 0 时，依次回退到 IQR / 1.349、标准差（ddof=0）；IQR 用 linear 分位插值。有效值全相等时变换为 0，NaN 保持 NaN。

y：每日横截面收益变换

在去掉停牌、进出场无成交后的有效收益上用同样的方法标准化，再软压缩。标签全相等会报错；每日有效标签至少为 max(1000, ceil(交集股票数 / 2))，不合格日期不跳过继续训练。

z=x−median(x)1.4826×MAD
g(z)={z|z|≤6sign(z)·[6+ln(1+|z|−6)]|z|>6
因子和标签均使用 c=6 的软压缩，不做 clip10 或硬截断。每日计算的目标描述相对位置，不是可直接解释成预期百分比的价格预测。

模型与 loss：梯度提升树 + 加权平方误差

y^i,t=LightGBMGBDT(X′i,t)
L∝∑t,iwi,t(y^i,t−y′i,t)2
objective = regression_l2；树复杂度受叶子数、深度、最小叶样本和 L1/L2 等参数约束。RankIC 和组合 Sharpe 是评价指标，不是该模型实际优化的 loss。

使用指定训练窗口内全部历史，不做时间衰减。若训练共有 R 行、D 个交易日，当天实际有效训练行数为 Nt，则 wi,t=RD×Nt。训练权重均值为 1，各日期的权重总量相等；bagging 仍按固定参数逐轮抽样。

组合如何形成

每日选股基数为因子交集内、未停牌且进场分钟有成交的股票，不预先按出场标签筛选。先按分数选择 ceil(q×N)，边界同分全部纳入，再去掉不可做对应方向的封板样本，不补位。no_long / no_short 要求进场分钟每笔成交都在对应涨跌停价 ±0.005 元内；日线无限价信息时不判封板。

入选股票等额，组合均值仅用有效标签；入选但缺标签的只数另记。纯空收益取空头平均标的收益的负值，多空为多头平均收益减空头平均收益。空组合记 0，多空任何一腿为空则整日记 0。Sharpe = √252 × 日均收益 / 日收益样本标准差（ddof=1）；常数预测截面的 RankIC 记缺失。

04

低 RankIC 与高 Sharpe，差异来自哪里

本节是已打开 test 后的解释性诊断。没有据此改模型、选因子或调整轮数。

平均相关系数，不等于组合收益的均值 / 波动

本次日均 RankIC 只有 0.0220，但它与每日多空收益的相关系数为 0.862，存在较强的同向变化。RankIC 序列的年化 ICIR 为 4.84，而多空 Sharpe 为 7.30；两者不能视作同一个统计量。即使逐日相关很高，收益映射的截距、斜率变化和尾部幅度也会影响组合结果。

分组均值大体随分数上升，D9 约 3.9bp，D10 约 10.6bp；最高分一组的增幅明显更大。模型的收益区分在最高分 10% 最突出，但“能力几乎全部集中于这里”仍偏强：中间分组之间有收益梯度，最低组相对全体也有差异。

这里有一层没有排除：去掉中间段会把分数的取值范围拉开，而秩相关本身就会随范围扩大而升高，与模型能力无关。等间隔对照 D1∪D5∪D10 为 @@POOL_CONTROL@@，说明升高中确实有一部分是机械的。本次没有做“在全体中随机抽同样只数、保留完整分数范围”的对照，因此不能把 @@POOL_LS@@ 全部算作模型能力。

全体那个数是怎么被摊薄的

把每天的 Spearman 按分数分组拆开：每只股票的贡献是它的分数秩偏差乘以收益秩偏差，再除以同一个归一化分母。按十分组求和，十组之和精确等于当天的 RankIC；对 176 天等权平均后，这十个数加起来仍然正好是 0.022040。

最低与最高两组合计占 @@TAIL_SHARE@@；三个组合会碰到的四组合计占 @@TRADED_SHARE@@；中间六组占了股票数的 60%，却只贡献 @@MIDDLE_SHARE@@。

为什么不把“正态理论预计 7.5bp”当作证明

正态线性近似还需要假定收益横截面方差、相关结构、分数与收益联合分布及分组条件。不能仅凭 RankIC 0.022 推出唯一的理论价差。这里直接展示实测分组均值、分布和组合波动，不把带假设的近似与实测差额归因成已经证实的机制。

代码截止时间支持什么结论

已检查发布清单和历史代码：cancel-phase 在 09:35:00 前截断，depth-match 也设置同一截止并关闭 future 输入；旧因子发布配置为 open5m。收益进场窗口从 09:35 开始，在检查到的配置上不与因子证据窗口重叠。

这里不能写成“已经证明没有未来数据”。本次没有对所有因子执行“删除截止后事件、重新计算并要求结果不变”的全量验证；冻结校准、其他参考数据及上游处理链也未逐项完成端到端因果性验收。旧因子清单中的旧标签家族不用于本次训练收益，本次已按新窗口重新核对。

离可执行回测还差什么

  • 进场有成交、整分钟是否封板等信息到分钟结束才完整可知，而收益使用同一分钟 VWAP；这是研究定义，不是逐笔执行模拟。
  • 未模拟买卖价差、冲击、成交量限制、空头可得性和费用，也未验证可卖库存安排。约 13bp 的名义多空日均毛收益可能对成本敏感。
  • 入选后按有效出场标签重算均值带有事后可得性口径；262 个入选股票日缺失标签。改成缺失计 0 后 Sharpe 为 7.303，当前样本影响很小，但仍应说明。
  • test 已被打开并用于分组、月度和敏感性诊断；以后若据此调整模型，不能继续把这段 test 当作从未见过的最终验收样本。

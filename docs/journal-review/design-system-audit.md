## 对照结论

| 项目 | 现有体系 | 日志扩展 | 结论 |
|---|---|---|---|
| 颜色 | 纸底、墨色、珊瑚焦点 | 复用现有 CSS 变量 | 未增加颜色令牌 |
| 字体 | 两种自托管衬线字体，系统正文与等宽回退 | 标题用衬线，控件与普通清单用系统正文 | 延续字体角色 |
| 状态 | 主导航深墨面反白 | 分段切换同样反白，日期与链条聚焦用珊瑚 | 状态语义明确 |
| 汇报标记 | 纸墨出版物语言 | 浅纸面、墨色左边界与衬线标题；图谱用空实点 | 不依赖颜色单独传达 |
| 数据图表 | 现有研究内容允许图表 | SVG 使用真实日期、轨道、线型、节点和文字 | SVG 是数据图表，无装饰性图形 |
| 小字 | 旧壳部分使用 `muted` | 日志说明、图例、计数等覆盖为 `text` | 避免沿用旧纸底上的低对比组合 |
| 窄屏 | 固定刊头与折行控件 | 默认清单、日卡单列、按钮至少 44px；图谱只在内部横滚 | 390px 首屏与验收记录一致 |
| 深度 | 版线与纸色层次，浮层才用阴影 | 日卡无投影，悬停读数复用 `shadow` | 未新增卡片层级语言 |
| 动态效果 | 既有控件短过渡与减少动态效果规则 | 日卡轻微显现、链条明暗；键盘关闭相关效果 | 保留当前实现，未新增动态令牌 |

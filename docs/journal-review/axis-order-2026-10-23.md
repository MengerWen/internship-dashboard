# 研究日志卡片与点的次序对应

2026-10-23，按用户补充的规则调整图内浮窗：按日展开只保持左右次序，上下自由错落；按链条展开只保持上下次序，左右自由错落。

自动排布先按真实点坐标选位，再以卡片中心保持相应轴的次序。日卡为后续卡片预留横向位置；链条卡在图底空间不足时继续利用左右空间并增加留白。卡片间距、避让和引线继续计算，点的位置不因卡片排布改变。返回结果保留调用方原有顺序，不改变卡片编号、焦点或导航。手动拖动和方向键调整可以越过自动次序，复位后恢复自动规则。

## 设计取舍

沿用既定「研究编辑台」和「推进图谱」。比较了只增加倒序惩罚、约束两个坐标轴、只在展开轴保序三种方法。采用只在展开轴保序：惩罚项仍可能留下倒置，同时约束两个轴会限制用户明确允许的错落方向。

核对全局、项目和插件技能清单，读取设计技能并记录当前路径、大小与 SHA-256，见 `artifacts/journal-axis-order/skill-inventory.json`。本次采用 frontend-design、design-taste-frontend、impeccable、ui-ux-pro-max 的既有视觉、空间关系、响应式和真实页面核对建议，保留 emil-design-eng 的键盘与减少动态效果行为，文案按 shuorenhua 核对。ui-ux-pro-max 的两次局部搜索没有找到直接对应的卡片保序建议，采用用户规定和现有布局约束。impeccable 的 layout 检测返回 `[]`。

本次是生产界面的局部排序调整，不启动 huashu-design 的新视觉方向选择，也不启动图片、幻灯片、文档、表格、模板或宠物的创作流程。没有新增字体、配色或依赖。

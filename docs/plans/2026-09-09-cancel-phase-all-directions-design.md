# 撤单因子：全部查看与分层导航

页面默认“全部查看”，同时展示 Total、Buy、Sell 的 72 个结果序列；“分别查看”筛选为单方向的 24 列。沿用现有已验收数据和图表，单文件离线版与网站展示版使用同一模板。

结果表增加方向列，支持 IC 数值降序、绝对 IC 降序、Rank IC 数值降序及原有绝对值排序。排序基于当前统计区间，空值排末尾，下载包含真实方向。

逐因子导航按七类定义、500/1000ms 周期、核参数、Total/Buy/Sell 展开。默认展开全部条目，每项显示所选统计区间的带符号 Rank IC；支持折叠、中文与编号搜索及原有参数筛选。导航评价区间与详情同步。

全部查看时，同一定义的三方向有一张对照表和三份完整详情。日度、月度、分组、OLS、分布与定义六个标签页同步，统计区间同步；图片、下载和原始证据各自绑定方向。分别查看仅保留所选方向。URL 保存查看方式、方向及因子编号。

验证覆盖全部 72 个导航数值、五种统计排序、两种模式切换、三份详情的区间和标签页同步、带方向的 CSV / JSON / 图片下载、离线图片及移动端布局。原始结果 JSON 与数值不变。

验证结果：11 项数据检查和 8 项浏览器测试通过，桌面及 390px 移动端截图已检查；汇总数据 JSON 与图表文件保持不变。

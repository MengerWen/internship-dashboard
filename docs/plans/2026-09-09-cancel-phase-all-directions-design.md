# 撤单因子：方向比较与分层导航

页面默认“全部查看”，可浏览 Total、Buy、Sell 的 72 个方向因子；“分别查看”筛选为单方向的 24 个因子。网站展示版与单文件离线版使用同一模板及已验收数据。

全区间结果的三方向图表按 Total、Buy、Sell 固定顺序并排显示，支持点击放大和下载。窄屏保留三列并在图表区域内横向滚动。

逐因子导航按定义族、时间周期、核参数、买卖方向逐层展示。点击标题选择其包含的内容：方向叶节点只显示该方向的单个因子，参数标题显示该参数下的方向因子，周期及定义族标题显示该组内所有符合筛选条件的因子。箭头只控制展开或收起，标题选择与折叠状态相互独立。

导航每个方向因子依次显示所选评价区间的 IC、Rank IC，保留正负号。页面文字、下载列名和日度图表统一使用 IC 简称。数学解释保留 Pearson 相关的方法名称。

第 5 节将筛选、排序结果大表和逐因子详情放在一起。搜索、定义族、周期、核、查看方式、方向、评价区间、排列方式及排序依据统一位于筛选行。排序支持编号、IC 数值、绝对 IC、Rank IC 数值、绝对 Rank IC 及绝对 G10−G1。表格、导航和 CSV 使用相同的筛选结果、评价区间与排列顺序。结果表限制显示高度并固定表头，完整结果可在表格内滚动查看。

“保留因子分组”按定义族、周期、参数和方向组织，在各层级内排序；大表标出定义族与周期分组。“不分组 · 全部混排”将每个方向因子作为独立条目，直接对全部符合筛选条件的因子排序，导航展示序号、编号、方向和参数，点击仅显示该项详情。从编号排序进入不分组模式时默认切为 IC 数值降序；已有数值排序保持不变。切回分组模式恢复层级与折叠状态。没有匹配项时显示空结果并禁用 CSV 下载。

当前范围内每个因子具有独立详情，图片和下载绑定该因子及方向。日度、月度、分组、OLS、分布与定义标签页同步，评价区间同步。URL 保存查看方式、方向、因子、选择范围、排列方式、排序依据及评价区间，支持直接进入单个方向因子或分组。

72 张日度图依据现有报告中的日度数组生成，标题使用 IC；原始结果 JSON 和因子数值保持不变。生成器提供仅生成日度图的入口，并同时生成两份 HTML。

验证覆盖全部 72 个导航数值、统计排序、范围选择、箭头独立折叠、筛选与区间同步、各因子方向的 CSV / JSON / 图片下载、离线图片、并排图表及移动端布局。11 项数据检查和 12 项浏览器测试通过，桌面与移动端截图已检查。

数学表达式使用内嵌的原生 MathML：七类因子定义、精确核函数与能量公式、收益标签、VWAP、IC、ICIR 及相关统计表达式均采用结构化排版。分数上下排列，根号、括号、求和与上下标按数学结构显示；长公式在自身区域内横向滚动。两份 HTML 均无需外部脚本、字体或网络即可显示公式，动态因子详情使用相同公式源。浏览器验证覆盖分子分母的实际位置、数学命名空间、范围与区间切换，以及离线和窄屏显示。

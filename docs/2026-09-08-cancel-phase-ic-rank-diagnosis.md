# 撤单相位因子：IC、Rank IC 与十分组收益的独立核查

结论：在已封存股票日面板与同日收益标签上，未发现当前 IC / Rank IC 的连接、排名、正负方向或汇总计算错误。十分组平均收益下降与微小正 Rank IC 同时存在，来自收益幅度和收益排名反映了不同的分布信息。该结论覆盖 24 列、601 日的全部 14,424 个日度评价组合，不等于对原始行情采集过程做了独立数据库重取验证。

## 1. 核查方法与实测误差

输入为 601 个因子分片、601 个同日标签分片及 10 个评价文件，共 1,212 个文件。先校验原始验收 manifest 的 SHA-256，再按日期与股票代码一对一连接。逐日检查键集合、重复键、有效价格的收益公式和成对有限样本。

正式评价使用 `algobench/interday_count_comparison.py` 中的 `daily_cross_sectional_ics`：先以 `code,date` 连接，随后在同一个有效样本中计算 pandas Pearson / Spearman 相关。独立实现位于 `tools/cancel_phase_diagnostics.py`：用 NumPy 稳定排序找到相等值区间、赋平均秩，再以去均值点积计算相关，不调用正式评价的 pandas corr 路径。

| 核查对象 | 结果 |
|---|---:|
| 日期 × 因子组合 | 14,424 / 14,424 |
| 逐日成对样本数 | 全部一致 |
| Pearson IC 最大绝对误差 | 2.7755575615628914×10⁻¹⁶ |
| Rank IC 最大绝对误差 | 5.551115123125783×10⁻¹⁷ |
| 十分组最高、最低组人数 | 全部一致 |
| 最高减最低组收益差最大绝对误差 | 0 |

另以 SciPy 直接复算 F22 的 2025-01-02：2,831 个成对样本，Pearson IC=0.026683411871658357，Rank IC=0.07404774904707523，与存储结果一致。

F22 原值舍入至小数点后 12 位，再重新计算日度排名，平均 Rank IC 为 0.004559798596，原值为 0.004559803585。浮点末位和并列秩的变化不足以解释目前的正负差异。正式因子数值没有因此被修改。

## 2. 同一份 F22 样本，三种相关如何变化

每日先计算，再对 601 日等权平均：

| 因子端 | 收益端 | 日均相关 |
|---|---|---:|
| 因子原值 | 收益原值 | −0.009351876 |
| 因子平均秩 | 收益原值 | −0.014984245 |
| 因子平均秩 | 收益平均秩 | +0.004559804 |

前两行都保留收益的幅度，符号为负。第三行把收益替换为相对名次，符号才转为微小正值。这比仅说“Pearson 和 Spearman 不一样”更具体：符号变化发生在收益取秩这一步。

公式为：

- IC₍d₎ = Corr(x₍d₎, r₍d₎)。
- Rank IC₍d₎ = Corr(rank(x₍d₎), rank(r₍d₎))，并列值使用平均秩。
- 报告日均 IC / Rank IC = 各自日度值的等权平均。
- 十分组收益 = 每日按因子平均秩百分位分组、组内对收益原值取均值，然后对有效交易日等权平均。

十分组图展示的是条件均值随因子组别变化。均值有序，并不保证整个条件收益分布按相同顺序移动：分布的离散程度、偏斜和尾部形状也可以变化。Rank IC 不等于“十个组均值与组编号之间的相关”，不能把十个均值压缩后得到的强单调性当成逐股票 Rank IC。

## 3. F22 的分组分布证据

以下各项均保持每日原有因子分组。先在组内计算，再对 601 日等权平均。

| 指标 | G1（低因子值） | G10（高因子值） |
|---|---:|---:|
| 平均收益 | 6.125425bp | −0.057054bp |
| 平均收益百分位 | 50.282423% | 50.479032% |
| 收益大于零的比例 | 47.887945% | 49.136146% |
| 日内组收益中位数的平均 | −3.208766bp | −4.040035bp |
| 每日全截面 P1/P99 缩尾后的均值 | 4.537770bp | −0.378477bp |
| 原均值减缩尾均值 | 1.587655bp | 0.321423bp |

G1 的平均收益明显更高，但平均收益名次略低，正收益比例也更低。十组平均收益百分位依次约为 50.282、49.705、49.854、49.858、49.722、49.857、50.001、50.144、50.273、50.479%，整体贴近 50%，并未呈现平均收益图中那种下降关系。

这说明低因子组的较高收益均值不能理解成“该组大部分股票都排在更高的收益名次”。它体现了收益幅度与分布形状的差异；这些统计本身尚不能识别是哪种交易行为或市场机制造成的。

### 最外侧尾部解释多少

按每天同一成对样本的收益 P1/P99 缩尾，阈值对当日各组共用，不改变因子、股票分组和有效样本。

- 原 G10−G1：−6.182479bp。
- 缩尾后 G10−G1：−4.916247bp。
- 被缩尾部分的组差贡献：−1.266233bp，约占原组差的 20.5%。

最外侧尾部确实有贡献，但缩尾后仍保留大部分负组差，因此“全是几个极端点造成的”不符合这项检查。这里的贡献指超出截面 P1/P99 阈值的那部分收益幅度，不是把最外侧 2% 股票的全部收益删掉。

### 是否只来自跨日平均

601 日中，F22 有 380 日 G10−G1 为负（约 63.2%）；其中 112 日同时 Rank IC 为正。异号现象在单日内部也存在，不能只用跨日汇总或某一年贡献解释。2024、2025、2026H1 的 Rank IC 为负、正、负则是另一层时期稳定性问题。

## 4. 累计 IC 与 OLS 散点

每日图现在包含四个面板：日度 Pearson IC、日度 Rank IC、累计 Pearson IC、累计 Rank IC。F22 的 601 日终点分别为 −5.620477630 和 +2.740441955；均为日度相关系数直接求和，不是策略净值。

全部成对有效股票日、含截距、每股票日等权的 F22 OLS 为：

`收益（bp） = 1.938796375 − 4.591839883 × 因子原值`

| 拟合指标 | 结果 |
|---|---:|
| 拟合股票日 | 1,705,782 |
| 汇集样本 Pearson r | −0.002494127 |
| R² | 0.000006220667（0.0006221%） |
| RMSE | 110.302827bp |

散点与 OLS 均使用全部成对有效股票日，F22 为 1,705,782 个真实点。点重叠时以透明度呈现密度，不抽样、不生成模拟数据。左图是完整数值范围，右图只是放大 x、y 的 P0.5—P99.5 视野；两条拟合线参数相同，没有按放大视野重新拟合。

汇集样本的相关系数不等于日度横截面 IC 的平均：前者把所有股票日合在一起求一次相关，后者每天单独中心化、标准化后再平均。R² 很小，说明这条原值线性拟合对单个股票日收益的解释比例很低。股票和交易日在面板中重复出现，样本数不能当作同等数量的独立观测，因此没有提供独立同分布假设下的 OLS t/p 值，也没有将拟合写成样本外预测能力。

## 6. 组内离散程度与误差棒

分组页按所选日期区间展示两种误差棒。左图为原有组均值 ± 典型日内组内标准差；后者定义为各有效日组内收益总体方差（ddof=0）等权平均后开方。它描述同一天、同一因子组内不同股票的收益差异，避免把跨日共同市场波动混进组内离散度。它不是均值置信区间，也不假定收益服从正态分布或保证包含 68% 样本。

右图为组日均收益的均值 ± 1.96 × Newey–West 标准误（lag 1），用交易日序列估计均值的不确定性。该图没有把数十万股票日当作互相独立的样本。95% 是正态近似描述性区间，未校正多重比较；左右图采用各自纵轴范围。

F22 全区间实测：

| 指标 | G1 | G10 |
|---|---:|---:|
| 原组均值 / bp | 6.1254 | −0.0571 |
| 典型日内组内标准差 / bp | 145.5645 | 65.2554 |
| 组均值 NW 标准误 / bp | 1.9619 | 2.1707 |
| 组均值 95% NW 区间 / bp | [2.2801, 9.9708] | [−4.3116, 4.1975] |

原组均值差只有 6.18bp，明显小于组内个股收益的离散尺度。这有助于解释单个股票层面的相关系数绝对值小，但不单独决定 Rank IC 的正负；收益取秩后的分布变化仍需结合前面的检查理解。

每个交易日按组样本数加权，将收益总体方差分成组内方差与组间均值差异两项：

`Var(r) = Σg (ng/N) Var(r|g) + Σg (ng/N)(mean(r|g)−mean(r))²`。

逐日验证该恒等式，再对每日的组内份额等权平均，F22 组内部分为 99.1283%，组间部分为 0.8717%。组间部分包括有限样本均值波动，不能视为样本外解释度，也不能等同于 OLS 的 R²。

G10−G1 使用每日两组收益之差直接估计 NW 标准误，保留同一天两组的协方差。其标准误为 0.9921bp，95% 区间为 **[−8.1270, −4.2380]bp**。因此，两组均值各自的区间虽有重叠，配对组差区间仍不含零；判断组差应使用后者，不能凭两条独立画出的误差棒是否重叠下结论。

新增计算覆盖 24 列 × 601 日，重新核对各组均值与有效天数，所有 45 个统计区间的组差标准误也与已有 NW t 一致。126 张静态科研图包含每个因子的全区间双图；页面误差棒和 CSV 下载随统计区间切换。
